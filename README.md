# AI-Powered-Customer-Support-RAG-Agent-
A fully offline AI customer support agent using local LLM (Mistral 7B), FAISS-based RAG over PDFs, Whisper STT, and Coqui TTS — no cloud APIs. It handles FAQs, troubleshooting, and product comparisons with voice I/O, multi-turn memory, a FastAPI backend, and a clean Streamlit UI.
